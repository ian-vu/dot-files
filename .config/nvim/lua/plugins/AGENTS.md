# plugins/

Plugin specs for [lazy.nvim](https://github.com/folke/lazy.nvim) — one file per concern.

## File layout

- **`ai.lua`** — AI assistant plugins.
- **`autocompletion.lua`** — Completion engine and sources.
- **`autoformat.lua`** — Format-on-save via conform.nvim.
- **`bufferline.lua`** — Buffer tab bar.
- **`dashboard.lua`** — Start screen.
- **`editing.lua`** — Editing enhancements (surround, pairs, etc.).
- **`explorer.lua`** — File explorer.
- **`git.lua`** — Git integration (fugitive, diffview, etc.).
- **`highlighting.lua`** — Treesitter and syntax highlighting.
- **`lsp.lua`** — LSP client configuration and fidget.nvim progress.
- **`navigation.lua`** — Navigation helpers (harpoon, etc.).
- **`obsidian.lua`** — Obsidian note-taking integration.
- **`sql.lua`** — SQL tooling.
- **`statusline.lua`** — Status line (lualine, etc.).
- **`telescope.lua`** — Telescope fuzzy finder.
- **`theme.lua`** — Colour scheme.
- **`ui.lua`** — UI tweaks (noice, dressing, etc.).
- **`languages/`** — Per-language plugin configuration — see `languages/AGENTS.md`.
- **`snacks/`** — Per-feature snacks.nvim configuration — see `snacks/AGENTS.md`.
